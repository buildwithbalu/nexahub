# NexaHub — Angular Student Service Portal

A polished Angular academic project demonstrating:
- Register/Login
- Authentication service
- Route guard
- Dashboard
- Calculator + calculation history
- Feedback form + validation
- Activity history
- Profile
- Responsive UI
- LocalStorage persistence

## Run

```bash
npm install
npm start
```

Then open http://localhost:4200

## Demo

Register a new account, then log in.

> Note: This project uses localStorage for classroom/demo authentication. It is NOT production-grade authentication. A real application should use a backend/JWT or Firebase/Auth provider.
